# Test fixtures

These files reproduce the *markup structure* of the real store pages (sas.am, yerevan-city.am API, carrefour.am, supermarket.am, parma.am)
as observed on 2026-10-08, but every product, price and id in them is **fictional test data**. They exist only so
parsers can be tested deterministically and offline. Never import them into a real database.
